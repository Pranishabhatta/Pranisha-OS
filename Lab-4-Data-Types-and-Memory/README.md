# Lab 4: Data Types and OS Memory Management

Operating Systems lab (ST5003CMD).

## Objectives

* Find the size of C data types with `sizeof`.
* Understand how a process uses memory (stack, heap, data, code).
* Compare stack and heap addresses using pointers.

## Files Included

| File            | Description                                              |
| --------------- | -------------------------------------------------------- |
| `lab1_sizes.c`  | Prints sizes of char, int, float, double, long, pointer  |
| `lab2_memory.c` | Memory segment addresses                                 |
| `pointer_heap.c`| Pointers, heap allocation and stack vs heap addresses    |
| `datatype.c`    | Data types example                                       |

## Example

```bash
gcc lab1_sizes.c -o lab1
./lab1
```

## Tools Used

Ubuntu Linux, GCC, Bash terminal
