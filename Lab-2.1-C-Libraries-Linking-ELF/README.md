# Lab 2.1: C Libraries, Linking and ELF

Operating Systems lab (ST5003CMD).

## Objectives

* Understand C standard libraries and header files.
* Compile a program with static and dynamic linking.
* Compare the two executables.
* Examine ELF headers and shared library dependencies.

## Files Included

| File                          | Description                          |
| ----------------------------- | ------------------------------------ |
| `procinfo.c`                  | C source program                     |
| `dynamic_program_headers.txt` | ELF program headers (`readelf -l`)   |

## Tools Used

GCC, `file`, `readelf`, `ldd`, `nm`
