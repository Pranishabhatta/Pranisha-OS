# Lab 1: Linux Fundamentals

## Objectives
- Practice Linux file and directory operations.
- Learn basic APT package management.
- Compile and execute a C program using GCC.
- Modify and recompile a C program.

## 1. File Operations
Practiced the following commands:
- `mkdir` and `cd` to create and navigate directories.
- `nano` to create and edit files.
- `cat` to display file contents.
- `cp` to copy files.
- `mv` to rename files.
- `rm` and `rmdir` to remove files and empty directories.
- `ls -l` to check file permissions.

Created `greeting.txt` containing "Hello Linux!" and practiced copying, renaming, and removing files.

## 2. APT Package Management
Commands covered:
- `sudo apt update`
- `sudo apt install build-essential`
- `gcc --version`
- `apt search python3`

## 3. C Programming and Compilation
Created `hello.c`, which prints a greeting and calculates the sum of two numbers.

Compiled the program using GCC and enabled compiler warnings with `-Wall`.

Modified the value of `a` from 10 to 200 and recompiled the program.

### Final Output
```text
Hello, Linux Lab!
Sum of 200 and 5 is 205
```

## Files
- `greeting.txt` — practice with text files and Linux commands.
- `hello.c` — C source code for the compilation exercise.
